Pinpoint — manual test plan

This page is both the checklist and the test target. Run /pinpoint test-plan.html, then hover & click any row, heading, button, or form field below to leave element-anchored feedback. It exercises tables, lists, code, a form, buttons, and sticky bars — a good spread of element types.

00  How to run

# in a Claude Code session
/pinpoint test-plan.html

# or from a terminal
pinpoint annotate test-plan.html        # opens browser, blocks until you finalize
PINPOINT_NO_OPEN=1 pinpoint annotate test-plan.html   # headless (for scripted tests)

03  Browser annotator (do these now)

  • Hover any element → floating label shows its <tag> + CSS selector.
  • Click an element → a numbered badge glues to it; a card appears in the sidebar.
  • Type a comment; it persists. Resolve (✓) dims it; Delete (✕) confirms first.
  • Click Locate (⤓) on a card → the page scrolls to that element.
  • Add a Page-wide note at the top of the sidebar.
  • Toggle Browse → you can click links/buttons without annotating; Inspect re-arms it.
  • Toggle the theme (🌙 / ☀️) → chrome flips light/dark; badges stay visible on the page.
